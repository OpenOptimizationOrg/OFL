# OFL - Optimisation feature library
The optimisation feature library aims to make optimisation feature sets easier to find by collecting them, annotated with information about high level properties they are appropriate for like the type of decision variables, number of objectives, and the presence of constraints. Where available references to papers describing the feature set and implementations are included. All collected feature sets are available through a searchable [website](https://openoptimizationorg.github.io/OFL/).

## Other libraries: Algorithms and features
In addition to the feature collection of OFL, we are also working on libraries for optimisation problems and algorithms:
- OPL - Optimisation problem library: [website](https://openoptimizationorg.github.io/OPL/), [github](https://github.com/OpenOptimizationOrg/OPL/) 
- OAL - Optimisation algorithm library: [website](https://openoptimizationorg.github.io/OAL/), [github](https://github.com/OpenOptimizationOrg/OAL/) 

Finally, an overview of the different projects is available [here](https://openoptimizationorg.github.io/Overview/).

## How to add feature sets
Contributions and corrections are very welcome, through pull requests, issue reporting, or email (see [contact](#contact)). 

## How to contribute to the project
Want to get involved to make OFL even better? Any help is welcome! 

We need help to 
- Extend the OFL infrastructure to make it easier to add, find, edit, extend, aggregate feature sets and their description 
- Advertise OFL 
- and, of course, add more features! 

Finally, you are also very welcome to propose your own ideas to make OFL better, and work on those. 

To get involved, just send an email (see [contact](#contact)), or talk to any of us.
